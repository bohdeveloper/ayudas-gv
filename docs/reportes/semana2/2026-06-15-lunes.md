### Implementación de `UsuarioRepository`

- Creado `auth/model/Usuario.java` como `record` Java inmutable (campos: `id`, `username`, `passwordHash`, `nombre`, `apellidos`, `email`, `idiomaPreferido`, `activo`, `roles`)
- Implementado `UsuarioRepository` con `NamedParameterJdbcTemplate` (parámetros nombrados `:username` en lugar de `?`)
- SQL JOIN en una sola consulta: `usuario → usuario_rol → rol` para cargar el usuario con todos sus roles en una sola ida a la BD
- Patrón de agrupación con `Map<Long, UsuarioBuilder>`: el JOIN devuelve una fila por rol; el mapa evita duplicar los datos del usuario
- `record UsuarioBuilder` privado como detalle de implementación interno al repositorio
- `Optional<Usuario>` como retorno: vacío si el usuario no existe o `activo = false`
- Probado manualmente con DBeaver: el SQL devuelve las filas correctas para el usuario `admin`
