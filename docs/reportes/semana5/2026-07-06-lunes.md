### DTOs y excepción 404

- `SeccionGeneralesDto`, `PersonaDto`, `SeccionInteresadosDto`, `SeccionContactoDto`, `SeccionAyudaDto` en `com.ayudasgv.expedientes.dto`, siguiendo el mismo estilo `record` + `@Schema` que `ExpedienteResumenDto`
- `DetalleAyudaDto` como **interfaz sellada** (`sealed interface ... permits`) con tres implementaciones (`DetalleAsignacionDiscapacidadDto`, `DetalleNacimientoAdopcionDto`, `DetallePartoMultipleDto`), cada una con su propio campo `tipo` como discriminante — Jackson serializa por el tipo en tiempo de ejecución sin necesitar `@JsonTypeInfo`, y el JSON resultante coincide exactamente con el tipo unión `DetalleAyuda` que ya existía en el frontend
- `RecursoNoEncontradoException` nueva en `com.ayudasgv.commons.exception` + handler en `GlobalExceptionHandler` → 404 con el mismo formato `ErrorResponse` que ya usan los errores 401/400/500
