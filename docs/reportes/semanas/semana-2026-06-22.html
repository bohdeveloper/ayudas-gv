Cliente HTTP — axiosClient.ts

  • Instancia axios centralizada con baseURL: '/api/v1' (proxy Vite: /api → http://localhost:8080)
  • Interceptor de petición: lee useAuthStore.getState().token y añade Authorization: Bearer <token> a cada request — acceso directo al store fuera de React, sin hook
  • Interceptor de respuesta: ante 401 llama a logout() del store — React re-renderiza y ProtectedRoute redirige automáticamente

API de autenticación — authApi.ts

  • login(credentials: LoginRequest): Promise<LoginResponse> — POST /api/v1/auth/login
  • Tipado estricto con tipos de types/index.ts ya existentes

Store Zustand — authStore.ts

  • create<AuthState>()(persist(...)) — middleware persist guarda sesión en localStorage bajo auth-session
  • Campos: token, username, nombre, roles, idiomaPreferido, isAuthenticated
  • setSession(data) rellena todos los campos; logout() los limpia
  • partialize: solo se persisten los campos de datos, no las funciones

Layout principal — MainLayout.tsx

  • Barra de navegación: marca, NavLink a /expedientes, nombre de usuario, LanguageSelector, botón logout
  • handleLogout(): logout() + navigate('/login', { replace: true })
  • <Outlet /> renderiza las páginas hijas de las rutas anidadas

Rutas protegidas — ProtectedRoute.tsx

  • Lee isAuthenticated del store Zustand reactivamente
  • Si no autenticado: <Navigate to="/login" state={{ from: location.pathname }} replace /> — guarda la ruta intentada
  • Si autenticado: renderiza {children}

AppRouter actualizado con rutas definitivas

  • Ruta pública /login: redirige a /expedientes si ya hay sesión activa
  • Ruta de layout (sin path): <ProtectedRoute><MainLayout /></ProtectedRoute> — protección + layout en una sola declaración
  • Ruta privada /expedientes: <ExpedientesPage /> placeholder (Semana 4)
  • catch-all: redirige a /expedientes

Redirección automática en 401

  • El interceptor 401 de axiosClient llama a logout() → store se limpia → ProtectedRoute redirige a /login en el siguiente render
  • Cubre token expirado sin lógica adicional
